## 02 - 文件快照与检索

- UTF-8 Markdown/TXT 快照保留相对路径、行号、SHA-256 版本及稳定片段 ID。
- 资料与输出目录分离，忽略隐藏文件/符号链接，限制文件数、体积与片段数量。
- 使用 rank-bm25，中文采用字符与相邻双字词；小数据集以词重叠过滤空命中。
- 可选 Embedding 余弦召回，通过 RRF 融合；拒绝零向量、非有限值和维度不一致。
- 加入三份自编示例资料，不包含个人原始资料。

## 03 - Agent 执行与报告

- 主代理可派发子代理；子代理只获得当前任务，不继承主代理聊天，也无派发/写入工具。
- 每个代理最多 3 次检索，共享调用与工具预算，通过信号量限制子代理并发。
- 任务总超时、请求超时、代理步数、任务数都有上限；失败时取消并等待同批任务。
- 终止结果由 Pydantic 校验，只允许引用本代理实际见过的片段；来源校验不等于语义正确。
- 提供兼容接口的真实模型模式与明确标记的确定性离线演示。
- 产出 report.md、sources.json、trace.json、run.json，日志不保存 API 密钥或完整聊天。
