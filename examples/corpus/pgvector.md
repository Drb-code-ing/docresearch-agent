# pgvector 示例资料

这是项目自编的演示资料，不是性能测试报告或完整产品文档。

pgvector 是 PostgreSQL 的向量扩展。已有 PostgreSQL 的小型应用可以在关系数据库中保存向量，并组合业务字段过滤与 SQL 查询。

对规模较小、关系数据关联较多的知识库，复用 PostgreSQL 可以减少额外运维组件。查询性能仍取决于数据规模、索引、过滤条件与硬件，需要在实际数据上验证。

关键词检索可以使用 PostgreSQL 全文检索，向量召回与关键词召回的结果需要独立融合。中文分词策略需要单独设计。

本资料未给出百万向量的延迟、费用或吞吐量，不能据此编造量化结论。
